Run `nx test ui` to execute the unit tests.

## Display components

- `fc-time` (formats `datetime`, `day`, `range`) and `zoneCity()`: a UTC instant in an IANA zone, `en-GB`, 24-hour clock, in a `<time datetime>` element.
- `fc-deadline`: "Respond by 14:30 (Warsaw)" with an `fc-badge` for the time left.
- `fc-badge`: small bordered pill for short labels.
- `fcMoney` pipe: amount in minor units and a currency code, "120 PLN" or "120.50 PLN".
